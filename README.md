# AUREON INVEST AI

Fase 1: painel B3 em modo assistido. Não executa ordens reais. O radar é uma lista demonstrativa, sem cotações ao vivo.

Instalação: npm install; configure VITE_SUPABASE_URL e VITE_SUPABASE_ANON_KEY em .env.local; npm run dev.

Para habilitar login e carteira, crie um projeto Supabase dedicado e execute sql/001_initial.sql. Nunca use chaves secretas no navegador.
